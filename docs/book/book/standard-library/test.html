Lira Programming Language

test

Lira Standard Library - Test Module Testing utilities and assertions

This module provides stateless testing utilities. Since Lira has limitations with module-level mutable state, the test counters are passed explicitly or tracked at the call site.

Usage: import std.test test("my test", assert_eq(2 + 2, 4)) summary(1, 1, 0) // total, passed, failed
