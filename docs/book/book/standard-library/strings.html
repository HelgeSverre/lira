Lira Programming Language

strings

Lira Standard Library - Strings Module String manipulation utilities Note: Named "strings" (plural) to avoid conflict with the "string" type keyword.

This module provides comprehensive string manipulation functions. It uses a combination of pure Lira implementations and host primitives (syscalls 30-39) for operations that require character-level access.
