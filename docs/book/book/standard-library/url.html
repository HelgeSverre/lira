Lira Programming Language

url

Lira Standard Library - URL Module URL parsing and encoding utilities

This module provides URL parsing, encoding, and manipulation functions. It uses host primitives (syscalls 110-111) for URL encoding/decoding and pure Lira for URL parsing.

Built-in functions (from host):

  • url_encode(str) -> str: Percent-encode string
  • url_decode(str) -> str: Decode percent-encoded string
