Pattern Matching

Destructure data, handle variants, and write expressive control flow with match expressions.

01

Match Basics

The match expression compares a value against patterns and executes the code for the first matching pattern. Unlike switch statements, match is an expression that returns a value.

Basic Syntax 
fn describe_number(n: int) -> string {
    return match n {
        0 => "zero",
        1 => "one",
        2 => "two",
        _ => "many"
    }
}

fn main() {
    println(describe_number(0))   // zero
    println(describe_number(1))   // one
    println(describe_number(5))   // many
}

main()

Each arm has a pattern, =>, and an expression. The underscore _ is a wildcard that matches anything. Patterns are checked top to bottom - the first match wins.

Match as Expression 
fn main() {
    let day = 3

    // Match returns a value
    let name = match day {
        1 => "Monday",
        2 => "Tuesday",
        3 => "Wednesday",
        4 => "Thursday",
        5 => "Friday",
        _ => "Weekend"
    }

    println(name)  // Wednesday
}

main()

Since match is an expression, you can assign its result to a variable or use it anywhere an expression is expected. All arms must return the same type.

02

Literal Patterns

Match against specific values - integers, strings, booleans, and more.

Integer Literals 
fn http_status(code: int) -> string {
    return match code {
        200 => "OK",
        201 => "Created",
        400 => "Bad Request",
        404 => "Not Found",
        500 => "Internal Server Error",
        _ => "Unknown"
    }
}

fn main() {
    println(http_status(200))  // OK
    println(http_status(404))  // Not Found
    println(http_status(418))  // Unknown
}

main()
String Literals 
fn parse_command(cmd: string) -> string {
    return match cmd {
        "start" => "Starting service...",
        "stop" => "Stopping service...",
        "status" => "Checking status...",
        "help" => "Available: start, stop, status",
        _ => "Unknown command"
    }
}

fn main() {
    println(parse_command("start"))   // Starting service...
    println(parse_command("restart")) // Unknown command
}

main()
Boolean Literals 
fn access_message(is_admin: bool) -> string {
    return match is_admin {
        true => "Full access granted",
        false => "Limited access"
    }
}

fn main() {
    println(access_message(true))   // Full access granted
    println(access_message(false))  // Limited access
}

main()

When matching booleans, all cases are covered without a wildcard since there are only two possible values.

03

Variable Bindings

Bind matched values to variables for use in the arm's expression.

Binding the Matched Value 
fn double_it(x: int) -> int {
    return match x {
        0 => 0,
        n => n * 2  // 'n' binds to any value
    }
}

fn main() {
    println(double_it(0))   // 0
    println(double_it(5))   // 10
    println(double_it(21))  // 42
}

main()

A plain identifier like n matches anything and binds it to that name. This is useful when you need to use the matched value in the arm's expression.

Combining Literals and Bindings 
fn describe_score(score: int) -> string {
    return match score {
        100 => "Perfect score!",
        0 => "No points yet",
        n => "Score: " + n
    }
}

fn main() {
    println(describe_score(100))  // Perfect score!
    println(describe_score(0))    // No points yet
    println(describe_score(42))   // Score: 42
}

main()

Specific cases are matched first (100, 0), then the binding pattern catches everything else. Order matters - put specific patterns before general ones.

04

Destructuring

Extract values from compound types like tuples and structs directly in patterns.

Tuple Destructuring 
fn get_first(pair: (int, int)) -> int {
    return match pair {
        (a, b) => a
    }
}

fn swap(pair: (int, int)) -> (int, int) {
    return match pair {
        (x, y) => (y, x)
    }
}

fn main() {
    let point = (10, 20)

    println(get_first(point))  // 10

    let swapped = swap(point)
    println(swapped)            // (20, 10)
}

main()

Tuple patterns extract each element into a variable. Use _ to ignore elements you don't need.

Nested Destructuring 
fn extract_middle(triple: (int, (int, int), int)) -> int {
    return match triple {
        (_, (x, _), _) => x
    }
}

fn main() {
    let data = (1, (42, 99), 3)
    println(extract_middle(data))  // 42
}

main()

Patterns can be nested to any depth. The underscore _ ignores values you don't need, making patterns more readable.

Matching Specific Tuple Values 
fn describe_point(point: (int, int)) -> string {
    return match point {
        (0, 0) => "origin",
        (0, y) => "on y-axis at " + y,
        (x, 0) => "on x-axis at " + x,
        (x, y) => "at (" + x + ", " + y + ")"
    }
}

fn main() {
    println(describe_point((0, 0)))   // origin
    println(describe_point((0, 5)))   // on y-axis at 5
    println(describe_point((3, 0)))   // on x-axis at 3
    println(describe_point((3, 4)))   // at (3, 4)
}

main()

Combine literal values and bindings in tuple patterns. Specific patterns are checked first, general ones catch the rest.

05

Pattern Guards

Add conditions to patterns with if guards for more precise matching.

Basic Guards 
fn classify_number(n: int) -> string {
    return match n {
        0 => "zero",
        x if x < 0 => "negative",
        x if x > 100 => "large",
        x if x % 2 == 0 => "even",
        _ => "odd"
    }
}

fn main() {
    println(classify_number(0))     // zero
    println(classify_number(-5))   // negative
    println(classify_number(200))  // large
    println(classify_number(4))    // even
    println(classify_number(7))    // odd
}

main()

Guards add an if condition after the pattern. The arm only matches if both the pattern matches AND the guard is true. The bound variable is available in the guard.

Guards with Destructuring 
fn describe_rect(rect: (int, int)) -> string {
    return match rect {
        (w, h) if w == h => "square of size " + w,
        (w, h) if w > h => "wide rectangle",
        (w, h) if h > w => "tall rectangle",
        _ => "unknown"
    }
}

fn main() {
    println(describe_rect((5, 5)))   // square of size 5
    println(describe_rect((10, 3)))  // wide rectangle
    println(describe_rect((3, 10)))  // tall rectangle
}

main()

Combine destructuring with guards to express complex conditions concisely. Both w and h are available in the guard expression.

Range-Like Guards 
fn grade(score: int) -> string {
    return match score {
        s if s >= 90 => "A",
        s if s >= 80 => "B",
        s if s >= 70 => "C",
        s if s >= 60 => "D",
        _ => "F"
    }
}

fn main() {
    println(grade(95))  // A
    println(grade(83))  // B
    println(grade(72))  // C
    println(grade(55))  // F
}

main()

Guards are evaluated in order, so check higher ranges first. This pattern is cleaner than nested if-else chains.

06

Matching Enums

Enums and pattern matching are a powerful combination. Match on variants and extract associated data.

Simple Enum Matching 
enum Direction {
    North,
    South,
    East,
    West
}

fn opposite(dir: Direction) -> Direction {
    return match dir {
        Direction::North => Direction::South,
        Direction::South => Direction::North,
        Direction::East => Direction::West,
        Direction::West => Direction::East
    }
}

fn main() {
    let dir = Direction::North
    let opp = opposite(dir)
    println(opp.__variant)  // South
}

main()
Enums with Data 
enum Shape {
    Circle(float),           // radius
    Rectangle(float, float)  // width, height
}

fn area(shape: Shape) -> float {
    return match shape {
        Shape::Circle(r) => 3.14159 * r * r,
        Shape::Rectangle(w, h) => w * h
    }
}

fn main() {
    let circle = Shape::Circle(5.0)
    let rect = Shape::Rectangle(4.0, 6.0)

    println(area(circle))  // ~78.54
    println(area(rect))    // 24.0
}

main()

When matching enums with associated data, destructure the data in the pattern. The variables r, w, and h bind to the enum's payload.

Option Type 
enum Option {
    None,
    Some(int)
}

fn unwrap_or(opt: Option, default: int) -> int {
    return match opt {
        Option::Some(value) => value,
        Option::None => default
    }
}

fn main() {
    let some_val = Option::Some(42)
    let no_val = Option::None

    println(unwrap_or(some_val, 0))  // 42
    println(unwrap_or(no_val, 0))    // 0
}

main()

The Option type is the idiomatic way to handle nullable values. Pattern matching ensures you handle both cases explicitly.

Result Type 
enum Result<T, E> {
    Ok(T),
    Err(E)
}

fn divide(a: int, b: int) -> Result<int, string> {
    if b == 0 {
        return Result::Err("division by zero")
    }
    return Result::Ok(a / b)
}

fn main() {
    let result = divide(10, 2)

    match result {
        Result::Ok(value) => println("Result: " + value),
        Result::Err(msg) => println("Error: " + msg)
    }

    let bad = divide(10, 0)
    match bad {
        Result::Ok(value) => println("Result: " + value),
        Result::Err(msg) => println("Error: " + msg)
    }
}

main()

Result types explicitly model success and failure. Pattern matching forces you to handle both cases, eliminating unhandled errors.

07

Exhaustiveness

The compiler checks that your match expressions handle all possible cases. This catches bugs at compile time.

Complete Coverage 
enum TrafficLight {
    Red,
    Yellow,
    Green
}

fn action(light: TrafficLight) -> string {
    // Must handle all variants - no wildcard needed
    return match light {
        TrafficLight::Red => "Stop",
        TrafficLight::Yellow => "Caution",
        TrafficLight::Green => "Go"
    }
}

fn main() {
    println(action(TrafficLight::Red))     // Stop
    println(action(TrafficLight::Yellow))  // Caution
    println(action(TrafficLight::Green))   // Go
}

main()

When all enum variants are explicitly handled, no wildcard is needed. If you later add a variant to the enum, the compiler will flag all matches that need updating.

Wildcard as Catch-All 
fn is_vowel(c: string) -> bool {
    return match c {
        "a" => true,
        "e" => true,
        "i" => true,
        "o" => true,
        "u" => true,
        _ => false  // Everything else
    }
}

fn main() {
    println(is_vowel("a"))  // true
    println(is_vowel("b"))  // false
}

main()

For types with many or infinite values (like strings), use _ to catch all unspecified cases. The wildcard must come last since it matches everything.
