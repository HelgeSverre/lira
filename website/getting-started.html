Get Started

Install Lira and write your first program in minutes.

Install toolchain
→
Write code
→
Run it
1

Prerequisites

You'll need Rust 1.70+ and the just command runner.

🦀
Rust 1.70+
⚡
just command runner
Install just via Cargo 
cargo install just
2

Clone & Build

Clone the repository and build the compiler and VM.

Terminal 
git clone https://github.com/HelgeSverre/lira.git
cd lira
just build
3

Write Your First Program

Create a new file called hello.li with this content:

hello.li 
fn main() {
    println("Hello, Lira!")
}
4

Run It

Terminal 
just run hello.li
Output Hello, Lira!
5

Install Globally Optional

Add Lira tools to your PATH for use anywhere.

Terminal 
just install

Installs lirac, liravm, lira-lsp, and lira-doc to ~/.local/bin

CLI Tools

lirac

The Lira compiler

lirac compile file.li -o out.lic
lirac check file.li

liravm

The Lira virtual machine

liravm run file.lic
liravm run-debug file.lic

lira-lsp

Language server for IDE support

lira-lsp

lira-doc

Documentation generator

lira-doc file.li
lira-doc stdlib/
